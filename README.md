# Secure Generative UI Input Sanitization

This example demonstrates a basic generative user interface (UI) that dynamically creates UI components based on user input. It highlights a critical security aspect: sanitizing user input before rendering it in the DOM. By using `textContent`, the example prevents potential cross-site scripting (XSS) vulnerabilities, which are crucial for secure Generative UI implementations.

## Language

`html`

## How to Run

Save the code as `index.html`. Open `index.html` in any modern web browser.
